# Contributing

Thanks for your interest in contributing to **Awesome AI Video Generation**.

## What belongs in this list

- AI tools, models, APIs, datasets, papers, tutorials, and communities relevant to AI video generation, editing, or avatar synthesis.
- Resources that are **currently active** as of submission (we periodically prune dead links).
- Quality and relevance over quantity.

## What does NOT belong

- Dead, abandoned, or paywalled-only resources with no public utility.
- Tools that have been superseded by better alternatives in the same niche.
- Promotional content disguised as community resources.
- Anything off-topic (general image generation, music generation, generic LLMs).

## How to add an entry

1. Fork this repo.
2. Edit `README.md`. Find the right section (Hosted Tools / Foundation Models / APIs / Open-Source / Datasets / etc.).
3. Add your entry alphabetically within the section using this format:

   ```
   - [Name](https://url) — One factual sentence describing what it does.
   ```

4. **Do not** use marketing language ("best", "amazing", "leading", "professional"). Stick to factual descriptions.
5. **Do not** bold, italicize, or otherwise visually emphasize entries.
6. Open a pull request. In the PR description, briefly note why this entry adds value (e.g., "covers a niche not yet represented", "active maintenance with recent releases", etc.).

## Review

Maintainers will review the PR for:
- Relevance to AI video generation
- Activity / liveness of the linked resource
- Description quality (factual, neutral, no marketing copy)
- Alphabetical placement within section

If accepted, your entry will be merged. If declined, you'll receive an explanation.

## Reporting dead links

Open an issue with the entry name and the broken URL. We'll verify and either update the URL or remove the entry.
